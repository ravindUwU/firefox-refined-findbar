Usage

userChrome.css styles allow advanced customisation by applying custom styles to elements of the Firefox UI. Should you choose to customise Firefox this way, you must do so with the understanding that these styles are inherently fragile because Firefox updates may change the structure of the UI in ways that are incompatible with the custom styles applied.

Enabling userChrome.css

Firefox doesn't load userChrome.css styles by default; enable them as described below. This process is only required once.

  1. Type about:config into the address bar, press "Accept the Risk and Continue". Search for the preference name toolkit.legacyUserProfileCustomizations.stylesheets and double-click it to set its value to true.
  2. Type about:support into the address bar, locate "Profile Folder" in the "Application Basics" table, and press "Open Folder".
  3. Make a folder named chrome within the profile folder.
  4. Make an empty file named userChrome.css within the chrome folder.

Installing refined findbar and organising userChrome.css

  1. Download userChrome.refined-findbar.css and move it next to userChrome.css. I recommend organising the chrome folder in the following structure so that styles can be individually toggled. 
    chrome/
	userChrome.css
	userChrome.refined-findbar.css
  2. Within userChrome.css, add an @import rule to include userChrome.refined-findbar.css.
    @import url(./userChrome.refined-findbar.css);
  3. Restart Firefox to see the changes take effect.

Updating refined findbar

  1. Download a new userChrome.refined-findbar.css from this site and move it next to userChrome.css, replacing the older version.
  2. Restart Firefox to see the changes take effect.

Handling breakages after a Firefox update

If you notice any breakages following a Firefox update (for example, an invisible findbar),

  1. Comment out the incompatible @import rules in userChrome.css to disable the styles.
    /* @import url(./userChrome.refined-findbar.css); */
  2. Restart Firefox and continue browing with those styles disabled.
  3. Once the fixed styles are available, replace the corresponding .css file (in this case, userChrome.refined-findbar.css) and uncomment the @import rule in userChrome.css.
  4. Restart Firefox and continue browsing with the fixed styles applied.

If the breakage is related to refined findbar and hasn't been reported already, please consider creating a GitHub issue.
